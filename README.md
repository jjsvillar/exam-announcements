# About

This project was made with SvelteKit.

## Developing

Once you've created a project and installed dependencies with `npm install` (or `pnpm install` or `yarn`), start a development server:

```sh
npm run dev

# or start the server and open the app in a new browser tab
npm run dev -- --open
```

## Local production deployment

Use Node.js 22.12 or newer and pnpm. Run from this project directory so the
server can find the existing `data/` and `uploads/` directories.

The included `pnpm-workspace.yaml` records the dependency build-script policy,
so a fresh pnpm install needs no interactive build approvals.

```powershell
pnpm install --frozen-lockfile
# First setup only; preserve an existing .env file:
Copy-Item .env.example .env
```

Edit `.env` before starting. For this computer only, set `HOST=127.0.0.1` and
`ORIGIN=http://localhost:3000`. For other devices on the same local network,
keep `HOST=0.0.0.0` and set `ORIGIN` to this computer's actual LAN address, for
example `http://192.168.60.100:3000`. Find the address with `ipconfig`.

Use that exact origin for both the exam display and the admin view. SvelteKit
checks the origin of form uploads. If the IP or port changes, update `.env`
and restart. `BODY_SIZE_LIMIT=50M` allows image/audio/video upload requests up
to that configured limit; adjust it if larger files are needed.

```powershell
pnpm run build
pnpm start
```

`build/` contains a standalone Node server generated by `adapter-node`.
`pnpm start` loads `.env` and runs it. Leave the terminal running; use Ctrl+C
to stop it. This does not install a Windows service or automatic startup.

- Exam view: `http://<configured-host>:3000/`
- Admin view: `http://<configured-host>:3000/admin`

Use port 3000 for both views. If an old preview is still running on port 4173,
stop it in its terminal with Ctrl+C to avoid editing a separate server's state.
For access from another computer, Windows Firewall must allow Node.js/TCP 3000
on the intended local network. This app has no admin login, so keep access to
trusted users and do not forward the port to the internet.

Keep `data/exam_state.json` and `uploads/` when replacing a build; they hold
the saved exam state and uploaded media. A single server process owns live
updates, so run one production instance. Rebuild and restart after source
changes; `.env` changes only need a restart.

## Previewing a build

For a temporary local preview, use `pnpm run preview --host 0.0.0.0` after
building. With npm, the equivalent is `npm run preview -- --host 0.0.0.0`;
the extra `--` forwards options to Vite. Preview uses port 4173 and is for
checking a build, not production hosting.
